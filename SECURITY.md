# Security Policy

Dhonomos manages CPEs at ISP scale -> security reports are taken seriously.

## Supported versions

Pre-1.0. Security fixes only on the latest commit of `main`.

## Reporting a vulnerability

**No** public issue, please. Report privately through GitHub:
[Report a vulnerability](https://github.com/pdh0085/dhonomos/security/advisories/new)
(Security tab -> Report a vulnerability).

Include: affected component (CWMP ACS, USP Controller, API, UI), version or commit,
reproduction steps, impact. Goal: acknowledge within 5 business days, then agree on a
disclosure timeline with you.
